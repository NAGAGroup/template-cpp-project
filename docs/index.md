# enginelib & mathkit documentation

Project documentation for the libraries in this repository. (In the
template these pages document the DUMMY project, written exactly as a
real project would document its own code — when you instantiate the
template, rewrite them for yours.)

## The libraries

- **mathkit** — header-only math helpers: `mathkit::lerp`,
  `mathkit::clamp01`, deterministic `mathkit::noise`. No link step, no
  runtime dependencies; include and go.
- **enginelib** — a compiled simulation engine built on mathkit:
  `enginelib::Engine` owns stepped time (`advance`/`elapsed`),
  `enginelib::combine` and `Engine::noise` expose mathkit through a
  stable ABI. Logs through spdlog.
- **demo-app** — a minimal consumer showing engine setup and stepping:
  `demo-app [steps]`.

## API reference

Generated by Doxygen from the public headers:

```sh
pixi run docs        # generates docs/api/ (cached; only reruns on changes)
pixi run open-docs   # generate if stale, then open in a browser
```

## Using the libraries

```cmake
find_package(mathkit CONFIG REQUIRED)
find_package(enginelib CONFIG REQUIRED)
target_link_libraries(my-target PRIVATE enginelib::enginelib)
```

Consume prebuilt packages through the `prod` environment, or add this
repo as a pixi source dependency (`subdirectory = "packages/enginelib"`).
Variant builds (static linkage, sanitizers, alternative compilers) are
available as `enginelib-<variant>` source packages under
`packages/enginelib/variants/`.

## Testing

```sh
pixi run test-all              # every test env for this platform
pixi run -e test test          # the default-flavor test suite alone
pixi run coverage              # instrumented run + per-file coverage table
```

Tests live in `packages/*/tests` as standalone consumer projects — they
`find_package()` the installed library, so a passing suite certifies
the install surface users actually get.
